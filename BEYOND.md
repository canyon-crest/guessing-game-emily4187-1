Above and Beyond Features:
1. Dark Mode Toggle: I added a CSS-based dark mode toggle using a checkbox (#toggle) and CSS selectors. When enabled, the background, container, and text colors change. This can be seen in the toggle section of the CSS. (After Line 107)
2. Live Game Timer: I implemented a real-time game clock using setInterval (function is called startElapsedTimer). This tracks how long each round lasts in seconds, which can later be used in the fastest game in the stats section. 
3. CSS Styling: I improved the visual design of the game using CSS to make it more organized and easier to use. I used Flexbox to create a two-column layout so that there is a sidebar (stats and leaderboard) on the left while the main game is on the right. I also styled elements like buttons, headings, and containers to make them more visually readable/consistent as well (including background gradients). The sidebar has its own distinct background/border to clearly separate it from the main game area. I think that this improves user experience by making the game look cleaner and more structured. This can be seen in the CSS. 
4. Custom "Other" Difficulty Mode: I added a custom difficulty option that allows the player to choose their own number range for the game. For example, if the user enters 50, the game will generate a random number between 1 and 50. In my code, this feature can be seen in the otherFunc() and hideOther(). otherFunc() displays the input box when the “Other” difficulty option is selected, and hideOther() hides it when a different difficulty level is chosen. That way the players can only input their max value when the other option is selected. I also added to the play() function for this feature so that if the custom option is selected the range would be set on the user's input, that way it would work in the range of the user's. I also updated reset() to hide/clear the box when the game restarts. This feature improves gives players flexibility and the ability to adust the game on their preferred challenge level.

Why these all improve the game: These features make the game more interactive, visually appealing, and also customizable (the other option). The dark mode improves usability while the CSS adds to the design.
